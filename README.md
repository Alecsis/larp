# Tokenline: The AI Learning Portal

An interactive AI learning portal for high school students, built for the **TSA Webmaster
2026–2027** theme, *Artificial Intelligence (AI) Learning Portal*.

- **3 learning lines:** AI Fundamentals · AI Tools & Techniques · Ethical & Responsible AI
- **18 lessons**, **12 interactive labs**, **5 challenges** (80 questions)
- XP, levels, badges, streaks and a progress dashboard, saved in the browser (no accounts)

## Quick start

```bash
npm install
npm run dev          # http://localhost:3000
```

## Checks

```bash
npm run lint
npm run typecheck
npm run check:content
npm run build && npm run start
```

For architecture, the progress system, accessibility and TSA compliance, see **[DOCUMENTATION.md](./DOCUMENTATION.md)**.
